# JavaScript Promise Challenges

A collection of small JavaScript exercises for practicing **Promises**. Each folder solves one simple challenge using `Promise`, `.then()` and `.catch()`.

## Challenges

| Folder | What it does |
|---|---|
| `addition` | Adds two numbers using a promise |
| `substruction` | Subtracts two numbers using a promise |
| `product` | Multiplies two numbers using a promise |
| `division` | Divides two numbers (rejects on division by zero) |
| `even or odd` | Checks whether a number is even or odd |
| `positive or negative` | Checks whether a number is positive or negative |
| `pass or fail` | Checks a student's grade and returns pass or fail |
| `message` | Logs a message using a promise |

## Run a Challenge

    cd addition
    node index.js

Change `addition` to any folder name. If the folder name has spaces, put it in quotes, for example `cd "even or odd"`.

## What You Learn

- Creating a promise with `resolve` and `reject`
- Handling results with `.then()` and errors with `.catch()`
- Using promises for simple decisions and calculations
